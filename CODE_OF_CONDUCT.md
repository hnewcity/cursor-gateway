# Code of Conduct / 行为准则

Be respectful, constructive, and considerate in issues, pull requests, reviews, and other project spaces.
Discuss code and ideas without personal attacks. Accept good-faith feedback and respect different backgrounds
and levels of experience.

Harassment, threats, discrimination, sexualized behavior, and publishing another person's private information
without permission are not acceptable. Do not post credentials or private conversations.

Maintainers may edit or remove harmful content, close discussions, or restrict participation to protect the community.
Concerns involving private information should be reported through a private maintainer channel; if one is not available,
request a private contact without posting the details publicly.

请在 Issues、PR、代码审查及其他项目交流中保持尊重，就事论事，接受善意反馈，尊重不同背景与经验水平。
不接受骚扰、威胁、歧视、人身攻击、性骚扰，或未经允许公开他人隐私。不要发布凭据或私人对话。
维护者可删除不当内容、关闭讨论或限制参与。涉及隐私的问题应通过私密渠道反馈；若暂无入口，
先请求私密联系方式，不要在公开区域描述敏感细节。
